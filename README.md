# Currency API

Консольное приложение для работы с курсами валют ЦБ РФ.

## Возможности

- Узнать курс валюты с показом изменения в рублях и процентах
- Конвертировать сумму из любой валюты в рубли
- Просмотреть список всех доступных валют

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/PavelMoiseev143/currency_project.git
cd currency_project
```

2. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

3. Активируйте виртуальное окружение:

**Windows:**
```bash
.venv\Scripts\activate
```

**macOS / Linux:**
```bash
source .venv/bin/activate
```

4. Установите зависимости:

```bash
pip install requests
```

## Запуск

```bash
python main.py
```

## Использование

После запуска появится меню:

```
1 - Узнать курс валюты
2 - Конвертировать валюту в рубли
3 - Показать все валюты
0 - Выход
```

Введите номер действия и следуйте подсказкам. Коды валют указываются в формате ISO 4217 (USD, EUR, GBP и т.д.).

## Источник данных

Курсы валют берутся из открытого API [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/), который использует официальные данные Центрального банка РФ.
